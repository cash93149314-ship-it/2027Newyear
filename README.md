## 卡司資訊
頁面卡司資料以頁面標示的更新日期與所列來源為準。尚未公布者標示「待公布後會陸續更新」。請於正式對外發布前再次核對各主辦單位最新公告。

## 正式招募提醒
正式開放報名前，請補上招募單位、工作地點、日期與班次、薪資、工作內容及可聯繫的報名窗口。本站為工作人員資訊整理頁，並非各縣市政府或演唱會主辦單位官方網站。

## 報名連結更新

報名按鈕採高對比亮金色設計。此 LINE 連結由網站提供者指定，網站不宣稱其為各跨年主辦單位官方招募窗口。

## 提前卡位資訊
地區卡司尚未公布，也可以先透過 LINE 聯繫活動小編，詢問活動資訊並提前登記成為工作人員。

- 薪資 NT$2,800／當日現領
- 提供交通補助
- 近距離與超強卡司互動（依現場工作安排）
- 工作內容：驗票協助、入場引導、活動現場支援、離場整理協助
- 實際薪資、交通補助與工作安排以活動小編提供的職缺資訊及雙方確認內容為準。
